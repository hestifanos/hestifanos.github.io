# Hermon Estifanos — Portfolio

A static personal software-engineering portfolio site built with HTML and CSS.

## Pages

- `index.html`: home page
- `about.html`: profile and background
- `projects.html`: selected projects
- `contact.html`: contact information

## Preview locally

Open `index.html` directly in a browser, or start a simple static server from the repository root:

```bash
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000). The site uses local image assets and `styles.css`; no package installation or build step is required.
